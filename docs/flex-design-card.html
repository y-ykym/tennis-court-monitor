「うけつけ」で出す利用者カード(フェーズ7)

施設の受付でバーコードをスキャナに読ませる / 代理受付のときは利用者番号を読み上げる、という現地用途。予約サイトにはログインせず、Secrets の利用者番号から Worker がバーコードの PNG を作って返すので 1 秒以内に出る。見た目は予約サイトの「利用者カード」モーダルに寄せた。寸法・色は実物のモーダルを Chrome で開いて getComputedStyle で測った値に合わせている。バーコードは実際に生成したものを埋め込んでいる(Chrome の読み取り機能で 00000000 と読めることを確認済み)。

LINE の Flex は px を自由に指定できないため、最も近い値を当てている。

モーダルと違うのは「閉じる」ボタンを置かないことだけ(LINE のメッセージは閉じられないため)。フッター自体を持たない。
呼び名(ゆうたそ / まきたそ)はカードに出さない(モーダルに無いため)。どちらのカードかは氏名で分かる。プッシュ通知の要約(altText)には残している。
拡大はバーコードをタップすれば PNG が全画面で開き、ピンチでできる。「よやく」カードは変えていない。
画像 URL は署名付きで期限なし。期限を付けるとトーク履歴に残ったカードが後日開けなくなり、電波の悪い受付で困るため。PNG は 約 670 バイトしかないので、回線が細くてもすぐ出る。
