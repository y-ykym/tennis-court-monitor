「よやく」カード: テニスベアの参加状態ラベルのパターン

2026-10-02 にログイン済みの Chrome から API を呼んで集めた実物の文言と、サイトの JS から分かった種類。左は今の見え方(文言があれば全部オレンジ)、右は「中止」だけグレーにする案。普通に参加している予定・自分が主催の予定は API が状態を返さないので、どちらも何も付きません。

文言(API の overCard.text)サイトの色種別どこで確認したか「よやく」に出るか
キャンセル待ちtagGreen(緑のチップ)今後の予定の実物(10/3 の練習会)出る。いちばん多いはず
中止tagDarkGray(濃いグレー)履歴の実物(過去の 1 件)。主催者が中止にすると、開催日前でも付く出る(開催日前に中止になったとき)
開催済みbearSecondWhiteGrey(薄いグレー)履歴の実物(9 件)出ない。「よやく」は今後の予定の API しか見ないため
申込中 / 承認待ち(文言は未確認)tagOrange(白太字で強調。JS に「申込中」用の判定がある)サイトの JS のみ。主催者の承認が要るイベントに申し込んだときと推測。実データでは未遭遇出る(文言は API のまま)
(なし = null)—普通に参加している予定(10/10)、自分が主催の予定(10/11)何も付かない(今までどおり)
